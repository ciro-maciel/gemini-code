Who meets Gemini Code

Every piece starts from the person who meets it: a developer who already uses one coding agent and wants several working at once.

Arrives

Curious and slightly wary, from GitHub, a post or a search.

Wants

Work done in parallel without babysitting, and nothing risky done behind their back.

Fears

Losing control of what ran, an unexpected bill, a tool that hides what it does.

Leaves with

Agents side by side, each in its folder, every risky action waiting for them.

  • Show the desk working: panes, listed steps, an approval waiting. Never an abstract picture of "AI".
  • Name things: the model, the agent, the folder and the cost.
  • Give before asking: the live demo and the open code come before any sign-up.
  • True facts only: a measured number carries its date and conditions.

The name, the mark and the trademark rule

Gemini Code, two words, both capitalized; gemini-code in code and URLs. In one line: an open-source desk of coding agents built around Google Gemini.

Mark only

Minimum 16 px on screen, 8 mm in print. Clear space: half the mark's width.

Horizontal lockup

Gemini Code

Google Sans Flex 600, tracking -0.02 em. Mark and word half a mark apart.

Decided: exactly like Gemini

Gemini Code is a showcase for Google: every screen and piece mirrors the Gemini app as closely as the system allows, to prove we build in Gemini's own design language. Decided by Ciro on 25/11/2026.

The trademark rule, absolute

Every public piece that carries the name carries the notice when it has room: "Independent open-source project. Not affiliated with, sponsored or endorsed by Google. 'Gemini' is a trademark of Google LLC." Short form: "Independent open source. Not affiliated with Google." Never Google's logo, the "G", the Gemini app icon or "official" phrasing.

The one limit: the look is ours to copy, Google's brand assets are not. We draw our own star and never use Google's official logo files, the "G", the Gemini app icon or Google's screenshots. That keeps the showcase in front of Google's designers, not its legal team.

Color

Tonal surfaces instead of borders, one blue for action and selection, and Google's four colors only while an agent works. Click a swatch to copy its token. The values switch with the theme.

Google's four colors: the working state only

  • The glow on a working pane's edge, the typing dots, the ring around the account avatar.
  • Never text, never a button fill, never success or error on their own: a color is a hint, the word is the meaning.
  • The wash behind this page is the one gradient a static piece may use as its ground.

Gemini Code

An open-source desk where several coding agents, built around Google Gemini, work on your software at the same time and ask a person before anything risky.

Independent open-source project. Not affiliated with, sponsored or endorsed by Google. "Gemini" is a trademark of Google LLC.

  • Everything reachable by keyboard; focus is a 2 px primary ring that follows the shape.
  • Dialogs start focus on the current choice and close on Escape. Option lists are radiogroups.
  • Every icon button and removable chip has a name. Live updates are announced politely.
  • Reduced motion turns animation off. Touch targets at least 40 px on phone.

How this system changes

The values live in packages/dashboard/src/neural-expressive.css; the rules for every other piece live in docs/2026-11-25-design-system.md. A deviation is a bug: fix the piece, or change the system on purpose with the reason written down.

A change

A small commit on main with its CHANGELOG line and screenshots in light and dark. The pre-push hook runs the preflight.

Open decision

A published VS Code theme in the same tokens.

Not built yet
