# Gemini Code workspace

Os agentes, documentos, modelos e habilidades deste workspace, em Markdown. Cada mudança fica registrada no histórico.

- `agents/`: um agente por pasta, com `INSTRUCTIONS.md`, rotinas, memória e `docs/` (documentos de trabalho).
- `templates/`: os modelos customizados da conta.
- `skills/`: as habilidades compartilhadas entre agentes.

Chaves do cofre, permissões, gasto e conversas nunca entram aqui.
