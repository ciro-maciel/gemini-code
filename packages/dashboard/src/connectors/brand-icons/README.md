# Brand icons

The mark of each app in the connector catalog, shown in its own colors so a
person recognizes the service at a glance. Each file is named by the app's `id`
in `packages/server/src/apps.js`.

- The SVGs come from [Simple Icons](https://simpleicons.org) 16.38.1 (CC0), with
  the brand's official color from its data set as the fill.
- `monday.png`, `canva.png`, `exa.png`, `context7.png` and `jam.svg` are the
  icons each service publishes on its own site, since Simple Icons does not
  carry them.

Every mark is a trademark of its owner, used here only to name the service a
connector reaches.
